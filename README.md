

# MCRith

MCRith is a community fork based on [Prism Launcher](https://github.com/PrismLauncher/PrismLauncher). It is an independent project and is not affiliated with the official Prism Launcher project.

## Download

Get MCRith from the [MCRith Releases Page](https://github.com/MxrGH/Super-Craig-Is-Gay/releases).
